## 2026-10-19 — 意图识别成为项目第一个模块

- 将仓库定位调整为从只读意图理解器开始实现 AgentOrbis。
- 清理旧对话状态机、数据库模型、迁移和基础设施诊断代码。
- 保留聊天测试页、严格输出契约、Anthropic 兼容模型适配器和离线模拟测试。
- 默认 Docker 环境收敛为 API 容器；后续模块需要时再接回持久化及相关基础设施。
- 将冻结数据集和不可变评测运行记录集中移动到根目录 `evaluation/`。
- 当前作者编写的合成开发集复测：原 80 条为 80/80，边界集 24 条为 24/24。结构错误最多纠正一次；这些结果不属于盲测或生产基准。
- 随后进入对话策略与状态归约阶段。

## 2026-10-19 — 对话策略与纯状态归约器首版

- 新增内存会话状态、任务状态、当前焦点和待补参数模型。
- 新增确定性策略，处理任务创建、回答待补参数、恢复、更正、取消和政策问答；任务目标不唯一时先澄清。
- 保存原始动作、已确认实体和歧义索引，支持后续逐项澄清，并允许明确的新任务打断澄清。
- 新增纯状态归约器，以原子方式生成新状态和领域事件；不连接数据库或调用外部工具。
- 当前策略与归约器尚未接入聊天 API，也没有阶段二评测；下一步先补充评测，再接入 API 工作流。

## 2026-10-19 — 聊天工作台接入对话状态

- 将原意图识别聊天页调整为 AgentOrbis 对话工作台，保留原有视觉样式并显示实时任务状态。
- 新增 `/api/v1/chat`，串联当前上下文构建、意图解析、对话策略、状态归约和不冒充真实执行的中文回复。
- 开发会话由 API 进程内存维护，支持同会话请求串行化、刷新页面恢复最近消息，以及新建会话。
- 工作台展示任务槽位、待澄清项、语义解析和状态事件；真实工具与 MySQL 仍未接入。
