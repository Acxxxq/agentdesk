# AgentOrbis 开发日志

**语言：**[English](../DEVLOG.md) | 简体中文

## 2026-10-19 — 意图识别成为项目第一个模块

- 将仓库定位调整为从只读意图理解器开始实现 AgentOrbis。
- 清理旧对话状态机、数据库模型、迁移和基础设施诊断代码。
- 保留聊天测试页、严格输出契约、Anthropic 兼容模型适配器和离线模拟测试。
- 默认 Docker 环境收敛为 API 容器；后续模块需要时再接回持久化及相关基础设施。
- 将冻结数据集和不可变评测运行记录集中移动到根目录 `evaluation/`。
- 当前作者编写的合成开发集复测：原 80 条为 80/80，边界集 24 条为 24/24。结构错误最多纠正一次；这些结果不属于盲测或生产基准。
- 随后进入对话策略与状态归约阶段。

## 2026-10-19 — 对话策略与纯状态归约器首版

- 新增内存会话状态、任务状态、当前焦点和待补参数模型。
- 新增确定性策略，处理任务创建、回答待补参数、恢复、更正、取消和政策问答；任务目标不唯一时先澄清。
- 保存原始动作、已确认实体和歧义索引，支持后续逐项澄清，并允许明确的新任务打断澄清。
- 新增纯状态归约器，以原子方式生成新状态和领域事件；不连接数据库或调用外部工具。
- 当前策略与归约器尚未接入聊天 API，也没有阶段二评测；下一步先补充评测，再接入 API 工作流。

## 2026-10-19 — 聊天工作台接入对话状态

- 将原意图识别聊天页调整为 AgentOrbis 对话工作台，保留原有视觉样式并显示实时任务状态。
- 新增 `/api/v1/chat`，串联当前上下文构建、意图解析、对话策略、状态归约和不冒充真实执行的中文回复。
- 开发会话由 API 进程内存维护，支持同会话请求串行化、刷新页面恢复最近消息，以及新建会话。
- 工作台展示任务槽位、待澄清项、语义解析和状态事件；真实工具与 MySQL 仍未接入。

## 2026-10-19 — 扩充随机意图评测

- 新增固定随机种子生成脚本和 110 条合成样例，覆盖退款、物流、政策问答、订单歧义及范围外输入。
- 修订标签口径后的数据集通过本地 API 和 `deepseek-v4-pro` 完成 110/110；HTTP P50/P95 约为 1.90/2.54 秒。
- 首轮复核后，评分纳入消息中明确表达的退款原因，并允许缺少订单号时报告参数歧义；两轮之间没有修改模型或提示词。
- 数据来自已知模板，未经独立人工复核；结果用于回归检查，不代表泛化能力或生产准确率。

## 2026-10-19 — 意图分类目录 v1

- 定义三个正式业务 ID、当前 API 别名、必填参数、对话动作和能力需求。
- 新增只读注册目录与中英文分类文档，区分缺参、候选冲突、任务歧义和业务用途不明。
- 规定放弃本地办理与撤销真实申请的边界；正式 ID 契约迁移和多 Agent 路由作为后续步骤。
- 分类目录与现有槽位、对话动作契约的兼容性检查及评测器测试共 21 项通过。

## 2026-10-19 — 正式意图 ID 接入与回归

- 将模型契约、提示词、策略、API 响应和聊天界面接入正式业务 ID，输出分类版本 `1.0`。
- 保留旧语义名称和旧咨询焦点的显式兼容；任务类型保持稳定，必填参数从注册目录读取。
- 生成五份新数据及 SHA-256 迁移清单，原数据和历史结果保持不变。
- 修复不同业务澄清间的订单串写风险；新目标缺参也可暂存旧澄清。
- 为原文片段和实体证据校验增加固定类别的纠正提示，仍最多纠正一次，不放宽证据检查。
- 完整离线测试 62 项通过；多轮与真实模型的全部回归结果见[迁移评测报告](../../evaluation/results/taxonomy-migration.zh-CN.md)。
