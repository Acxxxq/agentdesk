# 开发路线图

**语言：**[English](../ROADMAP.md) | 简体中文

## P0 — 可运行的业务垂直切片（当前基础版本）

- 使用 Compose 隔离部署 MySQL 8.4、Redis 和 API。
- 健康检查接口、创建/读取会话、发送对话轮次。
- 仅供演示的身份认证、租户范围和数据库迁移。
- 退款/物流任务状态机演示，支持纠正、取消和任务切换。
- 请求 ID 幂等处理和纯单元测试。

## P1 — 完整对话引擎

- JWT/OIDC 认证、RBAC 和租户范围查询。
- 使用 Pydantic 校验结构化 LLM 对话理解，并提供确定性回退逻辑。
- 明确管理待补充信息、澄清、任务恢复和取消策略。
- 会话级运行租约、短事务、事件日志和故障恢复。
- 受控工具循环 Agent Runtime、工具注册/访问控制及超时/重试策略。
- 完整场景测试和针对测试 MySQL 实例的集成测试。

## P2 — RAG 与客户体验

- 接入隔离的 Compose Milvus、集合版本管理和租户过滤。
- 文件处理流水线与 MinIO、混合检索、重排和证据引用。
- 客户聊天前端、客服操作追踪和工具审批界面。
- SSE 流式响应，使用持久化事件 ID 断线重连，不对重放能力作虚假承诺。
- 接入 OpenTelemetry/Langfuse，并完善个人信息脱敏与保留策略。

## P3 — 生产加固与基准评测

- 异步文档索引/评测 Worker、Outbox 和死信队列；Celery 按需引入。
- 外部订单/退款供应商幂等处理与结果核对/Saga 流程。
- 压力与混沌测试、迁移、备份、告警、部署和 CI 质量门禁。
- 可复现的公开评测、多轮对话基准数据集和延迟/成本看板。

## 面向公网前的完成条件

- 替换演示认证，落实真实用户身份和租户级数据校验。
- 配置密钥管理、Token 脱敏、CORS、限流、文件扫描和输入边界。
- 完成工具审计日志、操作审批、幂等处理和不确定结果恢复。
- 建立数据保留/删除机制、MySQL 备份、安全测试和可观测性。
